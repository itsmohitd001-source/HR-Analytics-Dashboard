
# HR-Analytics-Dashboard using Power BI
Interactive HR-Analytics dashboard

>>Project Overview

This project focuses on analysing employee attrition patterns and workforce trends using interactive dashboards built in Power BI.

The objective was to identify key drivers of attrition, understand workforce demographics.

 >>Objectives

-Analyse overall attrition rate and workforce composition.

-Identify high-risk employee segments.

-Examine salary, department, and tenure-based trends.

>>Dataset

-HR dataset containing employee demographics, compensation, job roles, performance ratings, and attrition status.

-Data cleaned and transformed using Power Query.

>> Methodology

-Data Cleaning & Transformation (Power Query)

-Data Modelling

-DAX Measures for KPI calculations

-Interactive Dashboard Design

>>Key Metrics Tracked

-Overall Attrition Rate (%)

-Attrition by Department

-Attrition by Age Group

-Attrition by Salary Band

-Job Role-wise Employee Distribution

T-enure vs Attrition Trend

>> Key Insights

-Higher attrition observed among early-tenure employees (0–2 years)

-Sales and HR departments showed relatively higher turnover

-Lower salary bands correlated with increased attrition probability

-Younger workforce segment showed higher mobility

>> Strategic Recommendations

-Strengthen onboarding & early engagement programs.

-Introduce targeted retention incentives for high-risk departments.

-Conduct compensation benchmarking for lower salary bands.

-Develop career progression pathways for early-career employees.
